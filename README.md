# Soccer-Analytics-Platform

An explainable soccer analytics and scouting platform that uses machine learning to evaluate player performance, discover player archetypes, identify statistically similar players, and support personalized player assessment. The project combines FIFA and FBref data with feature engineering, position-aware analysis, K-means and hierarchical clustering, PCA, cosine similarity, performance scoring, and an AI-assisted scouting workflow that incorporates user-provided qualitative knowledge into personalized player evaluations.
